# Magic Circle Editor

図形を組み合わせて魔法陣を描く、ブラウザー用のエディターです。パソコン・スマートフォン・タブレットで使えます。

**[Magic Circle Editorを開く](https://s-remi.github.io/Magic-circle-editor/web/)**

## はじめる

1. 「＋ 図形」で図形を追加します。迷ったら「作例を読み込む」から試せます。
2. 図形の種類や大きさを選び、「分割数」を増やして中心のまわりに並べます。
3. 色や重なりを調整したら、「画像を書き出す」で保存します。

## 操作

### 図形・線を追加する

「＋ 図形」では、円・楕円・葉形楕円・水滴・ハート・桜の花びら・クラブ（クローバー / ♣）・スペード・三日月・扇形・正多角形・星形・ダイヤ/尖り楕円を選べます。頂点数や尖り、三日月の欠け、扇形の開き角度は、種類のすぐ下で調整できます。

「＋ 自由曲線」を押し、キャンバスを指・ペン・マウスでドラッグして描きます。手ぶれをならし、離すと滑らかなベジェ曲線として確定します。選択中のレイヤーの分割数を引き継ぎ、描画中から中心のまわりに繰り返し表示します。分割数は後から1〜64に変更できます。

描いた後は図形と同じように移動・拡大縮小・回転できます。「曲線を描き直す」で線を置き換え、Escで描画を中止します。「もっとなめらかにする」で描いた曲線の細かい揺れをさらに抑えられます。描き直し・なめらか化はどちらも取り消せます。旧定規レイヤーを含む保存データは、読み込み時に自由曲線へ変換します。

### 文字を円弧に沿って配置する

「＋ テキスト」で文字レイヤーを追加します。文字を入力して入力欄の外を押すと反映されます。書体・文字サイズ・字間を調整でき、「文字の配置」で円弧と直線を切り替えられます。

魔法陣の縁に沿わせるときは「中心に配置」を押し、「円弧の半径」で縁までの距離、「回転」で円周上の位置を調整します。追加時は半径310の円弧で、文字列が上側の中央に揃います。分割による繰り返し・複製・重なり・保存・PNG/SVG書き出しにも対応しています。同レイヤーの合体は図形専用です。

文字は最大500文字・1行です。円周または直線の配置幅を超える文字は表示されないため、文字サイズや字間を小さくするか半径を大きくしてください。文字色は線色の設定に従い、線の太さは文字には適用しません。書体は端末に入っているフォントを使うため、別の端末で開いたSVGは見た目が変わることがあります。見た目を固定したい場合はPNGで書き出します。

### 大きさ・位置・繰り返しを調整する

- 図形を選び、画面上の「移動」「半径」「回転」などの目印をドラッグします。数値でも調整できます。
- 「分割数」で繰り返す数、「開始角度」で並べる向きを変えます。「分割の境界」を「はみ出さない」にすると、各区画の外へ出た線を隠します。
- 「中心に配置」で中央へ、「区画に収める」で区画内へ移動します。大きすぎて収まらないときは、先にサイズを小さくしてください。

図形の種類を変えると、縦横比や頂点数などはその種類の初期値に戻ります。位置・回転・分割数・線の設定は引き継ぎます。

### 色・太さ・背景を変える

画面上部の「線色」「太さ」「背景色」で全体の見た目を変えます。

図形ごとの「線の設定」が「デフォルト」なら全体設定に従います。「カスタム」にすると、その図形だけ別の線色・太さにできます。

### 重なり・前後関係を調整する

レイヤーは、追加した図形や自由曲線の単位です。一覧の上側ほど手前に表示されます。選択して複製・↑↓で並べ替え・表示切り替え・削除ができます。

| 設定                                | 効果                                                                           |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| 上位レイヤーとの重なり → 隠す       | 手前の図形の内側に入った線を隠します。手前が自由曲線なら、線の交差部分が対象です。 |
| 同レイヤーとの重なり → 隠す（合体） | 繰り返した図形を合体させ、内側の線を消します。自由曲線には使えません。             |

「同レイヤーとの重なり」では「時計回りに上に重ねる」「反時計回りに上に重ねる」も選べます。選んだ方向へ順に上へ重ね、下の図形の線を隠します。3分割以上では、最後と最初も同じ順序で一周つながります。中央へ寄せても開始位置だけ形が変わらないよう、重なっている図形の並びから手前を決めます。すべての図形が重なる部分は共通の領域として境界を描きます。2分割では通常の順序で重ねます。自由曲線には使えず、「分割の境界」が「はみ出さない」のときは重なりません。

### 補助表示・自動補正を切り替える

キャンバス上部の「プレビュー」で、補助線・選択表示・編集用の目印を除いた作品をブラウザーの表示領域いっぱいに確認できます。＋／−で中心を基準に表示倍率を25〜400%に変更できます。開くたびに全体が収まる100%に戻ります。「編集に戻る」または Esc キーで閉じます。

「分割ガイド」「選択ハイライト」「中心ガイド」は個別に消せます。

「自動補正」をオンにすると、移動や回転が中心・境界・一定の角度に揃いやすくなります。Altキーを押している間は解除できます。

### 取り消す・作り直す

「↶」「↷」で元に戻す・やり直すができます。キーボードでは `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` も使えます。

「新しく作る」「作例を読み込む」は現在の内容を置き換えます。確認画面でキャンセルできます。残したい作品は、先に「データ保存」をしてください。

## 保存・画像の書き出し

| やりたいこと         | 操作                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| 後で編集を続ける     | 「データ保存」で編集用ファイルを保存し、「開く」で読み込みます。     |
| 作品を画像として使う | 「画像を書き出す」でPNGまたはSVGを選びます。背景は透明にもできます。 |

補助線・選択表示・編集用の目印は、書き出した画像には入りません。

編集内容は同じブラウザーに自動保存されます。ただし、ブラウザーのデータを消すと失われるため、残したい作品は「データ保存」も使ってください。ページを開き直すと、取り消し履歴は消えます。
